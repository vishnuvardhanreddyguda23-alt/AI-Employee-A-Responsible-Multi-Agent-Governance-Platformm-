# Final Demo — 10–15 minutes

1. Log in as `admin@demo.local`.
2. Show the AI Workforce dashboard and seeded departments.
3. Open Agent Directory and select **Finance Agent (Live Demo)**.
4. Show performance, token usage and cost metrics.
5. Trigger a high-risk finance action.
6. Show deterministic governance blocking the action pending approval.
7. Open Human Approval and approve it.
8. Execute the approved action and show output validation.
9. Open Audit and show the request, approval and execution events.
10. Open Security and show a seeded suspicious/prompt-injection event.
11. Open Analytics/Observability for latency, execution, errors and cost.
12. Finish on Responsible AI to explain purpose, risk, human oversight, privacy, limitations and accountability.
